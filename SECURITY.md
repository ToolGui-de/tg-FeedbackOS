# Security Policy

This policy covers tg-FeedbackOS, ToolGui.de's fork of FeedbackOS and Quackback, and the
instance running at hub.toolgui.de.

## Reporting a Vulnerability

Please do **not** open a public GitHub issue.

- **Email** a report to [team@toolgui.de](mailto:team@toolgui.de) with a description,
  steps to reproduce and the potential impact, or
- **open a [private security advisory](../../security/advisories/new)** in this
  repository.

We reply as soon as we can and keep you updated while we work on a fix.

A vulnerability that also affects FeedbackOS or the original project belongs there as
well: report it to them through their own security policies.
