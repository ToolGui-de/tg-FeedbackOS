## What this is

tg-FeedbackOS is the instance ToolGui.de runs for its readers and tool providers at
[hub.toolgui.de](https://hub.toolgui.de): feedback board, roadmap, help center and
support inbox. ToolGui.de is a German guide to productivity apps and tools
([toolgui.de](https://toolgui.de)). The hub is used for ToolGui.de itself and is not
offered as a product of its own.

It is a fork of [FeedbackOS](https://github.com/PayGlue/FeedbackOS), PayGlue's fork of
[Quackback](https://github.com/QuackbackIO/quackback). The complete source code of the
running instance lives in this repository, on the `toolgui` branch. What changed compared
to Quackback is listed in [FORK.md](FORK.md).

For setup, configuration and self-hosting, follow the
[Quackback documentation](https://quackback.io/docs). Everything there applies here; the
additions are configured through the environment variables listed in [FORK.md](FORK.md).
